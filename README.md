# ECO: Sky Booster (에코: 스카이 부스터) — 1단계 플레이 가능 프로토타입

Three.js(0.160) 기반 3D 판타지 액션 RPG. 빌드 과정 없이 **순수 ES 모듈 + importmap**으로 동작합니다. 모든 라이브러리(three.js·simplex-noise·three-vrm·Lucide)는 `assets/vendor/`에 들어 있어 **인터넷 없이 로컬에서 100% 동작**합니다. 출처·라이선스: `THIRD_PARTY_LICENSES.md`

## 실행 방법

| 방법 | 명령 |
|---|---|
| **가장 간단 (Windows)** | `start.bat` 더블클릭 → 브라우저가 `http://localhost:8080`을 엽니다 |
| Python 직접 | `python -m http.server 8080` → `http://localhost:8080` |
| Vite (Node 설치 시) | `npm install` → `npm run dev` |

- `index.html`을 더블클릭(file://)하면 ES 모듈이 차단되므로 **반드시 로컬 서버로** 여세요.
- **모바일 테스트**: PC와 같은 Wi-Fi에서 `http://<PC의 IP>:8080` 접속 (IP 확인: `ipconfig`). 방화벽 허용 필요.

**AUTO**: 몬스터 추적(멀면 부스터 돌진) → 3.5m 밖에서는 권총 연사하며 접근 → 3.5m 안에서는 검 3연타 → 쿨마다 회전베기/버스트 → 드랍·채집물 자동 수거 → HP 30% 이하 후퇴. 조이스틱/버튼을 만지면 즉시 수동 우선(버튼이 노란색), 손을 떼고 0.7초 뒤 자동 복귀.

## 진행 흐름
1. **초원 섬**: 몬스터 처치·나무/광석 채집 → 각성의 비석(📜)·바람 정령 획득 → 10킬 후 **킹 슬라임** 등장 → 처치하면 다음 섬 게이트 + 땅 정령 봉인 해제
2. **수정 동굴 섬** (물·번개) → 3. **빛과 어둠의 유적** (빛·어둠) → 4. **보스 섬** (공허룡 니힐)
3. 7정령 수집 시 **엘레멘탈 마스터** 자동 발동 (버프 1.5배, 7정령 무지개 궤도, 버스트 해금)
4. 주인공 1인 전투: 검 3연타 · 권총 연사 · 7대 정령 보조 공격/엘레멘탈 버스트 · 부스터 대시 회피 (동료/서포터 없음)
5. 재료로 검/권총/곰인형 부스터 +10까지 강화 (단계별 이펙트 색 변화, +10은 무지개)
6. 🏠 집에서 가구 제작·배치 → 최대HP/공격/방어/정령/드랍/재생/강화확률 보너스 (같은 가구 2개까지 적용)

모든 진행 상황은 localStorage에 자동 저장됩니다 (10초마다 + 주요 행동 시). 초기화: 🎒 가방 → 저장 초기화.

## 주인공 .glb 모델
- 탐색 순서: `assets/models/eco-hero-girl.glb` → `models/eco-hero-girl.glb` → 둘 다 없으면 기본 3D 파츠 캐릭터로 폴백.
- 자동 처리: 키 1.75m로 크기 정규화, 바닥/중심 정렬, 노멀 없으면 계산, 툰 셰이딩 적용.
- **화이트 메시**(텍스처·버텍스컬러 없음)면 높이 기반 컬러 페인트(은발/피부/빨강 재킷/검은 스커트/부츠) 자동 적용 — 가방 → 설정에서 ON/OFF.
- 모델이 엉뚱한 방향을 보면 **F9**(또는 가방 → 설정)로 90°씩 보정 (저장됨). 등의 곰인형 부스터와 검/권총 위치는 메시를 스캔해 자동으로 맞춥니다.
- 애니메이션 클립이 있으면 첫 클립 자동 재생, 없으면 프로시저럴 모션(이동 기울기·베기 팔 휘두르기·부양).

## 전투 손맛 · 그래픽 디테일 (v0.4)

**전투**
- **거리 기반 자동 무기 전환**: 공격 입력 하나로 적 표면까지 3.5m 초과면 왼손 권총, 이내면 오른손 검 (경계 떨림 방지 0.4m 히스테리시스, 공중 몬스터는 권총). 현재 무기는 버튼이 하늘색으로 빛납니다.
- **권총**: 초당 11발(기존 8발) · 탄속 72m/s. 총구 화염(십자 화염 + 별 섬광), 빛나는 탄환 트레일, 피격 스파크, 팔 반동. 발당 피해는 낮춰 DPS는 기존과 비슷합니다.
- **검 3연타**: 0.15 · 0.15 · 0.21초(기존 0.22 · 0.22 · 0.30). ① 우상→좌하 대각선 ② 좌상→우하 대각선 ③ 넓은 가로 베기 + 전방으로 날아가는 검기. 셰이더로 쓸어 그리는 초승달 아크 + 바람 궤적 선, 베기에 맞춘 상체 비틀기.
- **타격감**: 검 명중 시 0.03초(3타 0.055초) 히트스톱, 몬스터 흰색→붉은색 피격 플래시 + 스쿼시, 부드럽게 밀려나는 넉백, 우측 콤보 카운터(10/30/60타에서 색 변화).
- **부스터**: 양쪽 노즐 3겹 플라즈마 불꽃(파랑/하늘빛/백색 코어) + 노즐 글로우, 돌진·부양 시 잔상(Afterimage).
- **카메라**: 전투 중 적 쪽으로 시선을 당기는 추적 + 근접전 줌인, AUTO에서는 적이 화면 안쪽에 오도록 천천히 회전, 돌진 시 FOV 펀치. 엘레멘탈 버스트는 줌인 → 슬로모션 → 화면 플래시 → 줌아웃.

**그래픽**
- 주인공·몬스터·NPC 발밑 접촉 그림자(기존 실시간 그림자맵과 병행), 이동 기울기·선회 롤·호흡·무기 대기 모션.
- 섬 가장자리 보조 폭포 2줄기(샘 → 실개천 → 낙수), 성소·제단·게이트·가장자리 빛기둥, 돌길 이끼, 섬마다 꽃잎/단풍잎/재 파티클.
- 나무·바위에 높이 그라데이션 + 태양색 림라이트, simplex-noise 기반 지면 색 얼룩·절벽 굴곡.

**모바일 최적화**
- 탄환 트레일·접촉 그림자는 InstancedMesh 각 1 드로우콜, 검기·섬광·총구 화염·잔상은 풀링(전투 중 지오메트리/머티리얼 생성 0).
- 39만 삼각형인 주인공 GLB는 로딩 때 정점 클러스터링으로 약 2.2만 삼각형 프록시를 만들어 **그림자 패스와 잔상**에만 사용합니다 (프레임당 삼각형 약 103만 → 66만, 화면에 보이는 본체는 원본 그대로).
- 모바일에서 파티클 상한(2600→1400), 검기·잔상 풀 크기, 이끼·빛기둥 수를 줄입니다.
- 로딩 때 이펙트 셰이더를 미리 컴파일해 첫 타격 끊김을 없앴고, 연사 피해 숫자는 0.15초 단위로 합산 표시합니다.
- 기존 자동 품질 조절(해상도 → 블룸 → 그림자)은 그대로 동작합니다.

**주인공 VRM**: `assets/models/eco-hero-girl.vrm`(또는 `models/…vrm`)을 넣으면 GLB보다 먼저 불러옵니다. (@pixiv/three-vrm, MToon 머티리얼 유지)
